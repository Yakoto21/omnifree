# Avisos de componentes de terceiros

O OmniFree usa bibliotecas e motores de código aberto. A edição leve inclui dependências JavaScript e o FFmpeg fornecido pelo pacote de desenvolvimento. A edição completa poderá incluir cópias portáteis de motores adicionais na pasta `engines`.

Antes de publicar uma edição com binários adicionais, mantenha nesta pasta os textos de licença, avisos de copyright, arquivos de atribuição e, quando exigido, a oferta do código-fonte correspondente. Use somente pacotes oficiais ou builds cuja redistribuição seja permitida.
